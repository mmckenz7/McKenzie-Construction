# Fence Visual Measure

An isolated, local-only 2D fence measurement prototype.

```sh
npm install
npm run validate
npm run dev
```

Open the local URL, add the measured house when needed, choose **Draw**, then tap or click to place connected points. Draw continues from the last point by default. Choose **Separate line** to start a divider or secondary fence anywhere. **Site walk** provides large mobile controls that request a fresh high-accuracy browser location only when **Mark** is tapped. The first fix establishes a transient local origin, later fixes add plan points, and the latest GPS-shaped run can immediately be replaced with an exact tape, wheel, or laser measurement. Latitude and longitude are never serialized.

On a phone, Site Walk becomes a focused field view: the large GPS action, separate-line action, finish action, zoom controls, and plan remain visible while the header, materials, property tools, empty inspector, and footer move out of the way. Portrait and landscape layouts keep the mark action thumb-sized and preserve a useful plan viewport. Start on an HTTPS deployment because mobile browsers generally require a secure page for location access. Stand still at each point, tap the mark action once, then replace the latest GPS run with the exact tape, wheel, or laser length before moving on.

While drawing, the changing run length stays in a fixed on-canvas measurement box so it does not cover the target or reference image. After placement, completed dimensions render beside their fence runs with leaders, automatically separate from nearby labels, stay inside the visible plan, avoid unrelated runs when space allows, and remain a stable visual size while zooming. A selected span provides **Flip dimension side** for tight layouts plus **Auto-position dimension** to return it to automatic placement.

**Property** provides free/manual reference links for Acres, KGIS, and Google Maps. On desktop, open the permitted Acres or KGIS view and use **Capture map tab**, or copy a screenshot and use **Paste image**; no screenshot file needs to be managed. PNG, JPEG, and WebP upload remains a fallback. The captured image is compressed to a maximum 2,000-pixel edge, can be positioned, rotated, faded, locked, and scaled by entering a known distance and tapping its two endpoints. Before fence points are drawn, **Trace 4 house corners** uses the first traced wall as the horizontal reference, rotates only the local reference image, and creates an axis-aligned measured house footprint from the four marked corners. Automatic building detection remains deferred until real Acres/KGIS captures prove it can be trustworthy. Reference image, grid, house, and dimension visibility are independent. **Save local** stores the reference separately from the fence design in this browser only. It is excluded from fence history and totals and never replaces field measurements. Google Maps remains a separate viewer.

Free angle is the default. After the first run, optional 45°/90° assistance uses the previous segment's bearing as its reference, so a straight continuation remains straight even when the whole fence is diagonal to the screen. The grid has its own always-available toolbar toggle and can be hidden without changing snapping, measurements, or saved geometry. Select a fence run where the gate should sit, choose **Add gate**, then enter its style, total width, and exact fence length from the selected run's starting post to the near side of the gate. Clicking the run supplies the initial distance. The gate replaces only that portion of the straight run and does not change its bearing or combined length; its exact location splits fence-panel rounding before and after the opening. Selecting the finished gate shows its distance from the previous post. The displayed total combines every perimeter, divider, and gate run. Saving uses only this browser's local storage.

**Materials** first requires **Confirm layout for takeoff**. Every fence type uses the same Draw, Edit, gate, closure, relative-angle, exact-length, and line-topology rules; material selection appears only for the confirmed drawing revision. Any later geometry edit returns Materials to confirmation before recalculating. The selected **Black Aluminum** or **Treated Pine Privacy** takeoff never changes the drawing. Treated Pine Privacy is 6 feet high with touching 6-inch 1×6×6 pickets, 8-foot maximum bays, three 2×4×8 rails per bay, treated 4×4 posts, one 50 lb concrete bag per installed hole, and 10% purchase waste on all lumber. A single gate uses five 2×4 frame pieces and two hinges; a double uses ten frame pieces, four hinges, one latch, and one drop rod. Gate pickets are included. Picket fasteners are six screws per installed picket—two at each of three rails. Preliminary structural fastening uses 12 rail-to-post screws per installed bay and 12 gate-frame screws per leaf. Hinge, latch, and drop-rod mounting fasteners are assumed included with those hardware items. The summary distinguishes installed quantity from the 10% lumber allowance, and **Copy takeoff** produces the selected deterministic report. Both takeoffs remain session-only, preliminary, no-pricing derivations and are never saved into measurement geometry.
