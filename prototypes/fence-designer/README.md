# Fence Visual Measure

An isolated, local-only 2D fence measurement prototype.

```sh
npm install
npm run validate
npm run dev
```

Open the local URL, add the measured house when needed, choose **Draw**, then tap or click to place connected points. Free angle is the default and house-edge anchors stay active independently of optional 45°/90° assistance. A dashed live run shows feet/inches before placement. Start the path on one house edge, enter the measured runs, then choose **Close to house** and tap the second connection: every run stays fixed while the flexible angles are redistributed across all available corners. Select a point and choose **Add gate** to insert a single or double gate with an exact total opening width. Escape cancels the current tool, the wheel zooms only the plan, and two-finger or Command-drag pans without changing tools. Saving uses only this browser's local storage.
