# Fence Visual Measure

An isolated, local-only 2D fence measurement prototype.

```sh
npm install
npm run validate
npm run dev
```

Open the local URL, choose **Draw**, then tap or click to place connected points. After the first point, a dashed live run shows its feet/inches before placement. **Snap on** uses the one-foot grid, house edges, and 45-degree run bearings; turn it off for free angles. Select a point or span to edit it. Saving uses only this browser's local storage.
