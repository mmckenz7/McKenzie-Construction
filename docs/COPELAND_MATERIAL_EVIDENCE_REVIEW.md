# Copeland Material Evidence Review

Date: 2026-08-31

Purpose: record the benchmark evidence boundary without placing customer,
property, contract, supplier-quote, or purchasing details in repository history.

## Confirmed evidence classes

The private benchmark packet contains a project plan, pre-construction photos,
and separately held project records. Only the frozen plan and the approved,
privacy-minimized before-condition photos are model-visible for the blind
estimating-time run.

Financial records, invoices, completed-work media, later changes, and actual
cost information remain hidden evaluation material. They are not model input
and must not be copied into repository documentation or generated reports.

## Unrelated supplier record

A supplier quote found during evidence review could not be tied reliably to the
Copeland benchmark. Its project identity and quantities did not align with the
confirmed benchmark packet. It remains quarantined and must not be used as
Copeland input, truth, correction evidence, material mapping, or scoring data.

The private source manifest records the exclusion without exposing the quote's
identifier, addresses, prices, product lines, or customer information.

## Benchmark rules

1. Resolve project identity from the private frozen manifest, never from a
   repository label or guessed address.
2. Send only explicitly permitted, hash-verified sources to a provider.
3. Keep financial and as-built evidence outside the candidate-generating
   context.
4. Require a positive project match before any supplier record can enter hidden
   truth or reviewed material mapping.
5. Store public benchmark reports using non-address identifiers and aggregate
   metrics only.
6. Reject outputs that expose private paths, addresses, financial values,
   provider payloads, or customer-identifying details.

## Current limitation

The benchmark may evaluate scope extraction and measurement recognition without
an exact supplier receipt. Supplier-product matching and price accuracy require
separately reviewed, correctly identified evidence and are outside this
repository-safe summary.
